📲 Kenapa Tiada Butang Home Screen?

Pelayar telefon (Chrome/Safari) menyembunyikan fungsi "Add to Home Screen" jika aplikasi dibuka di dalam mod Preview. Untuk mengaktifkannya, pilih salah satu cara mudah ini:

Cara 1: Muat Naik Percuma (Paling Disyorkan untuk Home Screen)

  1. Tekan butang "💾 Simpan Fail" di bawah untuk muat turun fail MainanBayi.html.
  2. Buka laman percuma tiiny.host atau app.netlify.com/drop di Chrome/Safari.
  3. Muat naik fail tersebut untuk dapatkan pautan web anda sendiri.
  4. Buka pautan itu → Barulah menu "Add to Home Screen" akan muncul!

Cara 2: Buka Terus Tanpa Internet (Offline)

Selepas tekan "💾 Simpan Fail", buka aplikasi Files / My Files di telefon anda, cari fail MainanBayi.html di folder Downloads, dan tekan untuk terus bermain tanpa internet!
